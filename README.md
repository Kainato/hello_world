# Olá Mundo! 🌍

Este projeto foi criado para explorar e brincar com **animações em Flutter**.

A ideia inicial é simples, mas divertida: exibir vários "Olá Mundo" em diferentes línguas, alternando a cada alguns segundos com transições animadas e personalizadas.

---

## 🎯 Objetivo

Criar um aplicativo que demonstre **animações, transições e efeitos visuais** utilizando do framework Flutter.

---

## 🚀 Funcionalidades

- Exibição de mensagens "Olá Mundo" em várias línguas.

- Troca automática de texto a cada poucos segundos.

- Animações e transições personalizadas entre os textos.

- Estrutura simples e extensível para adicionar novas animações.

---

## 🛠️ Tecnologias Utilizadas

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)  

---

## 🔧 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/flutter-animations-ola-mundo.git
```

2. Acesse a pasta do projeto:

```bash
cd flutter-animations-ola-mundo
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute o app: 

```bash
flutter run
```
